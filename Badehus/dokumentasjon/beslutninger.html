    Arkitektur, eierskap og adresse

    Anbefalt arkitekturVedtatt 25.10.2026

    GitHub Pages (statisk frontend) + én Cloudflare Worker (innlogging, regelvalidering, skriving) + privat GitHub data-repo (JSON/JSONL/CSV, Git som revisjonsspor) + GitHub Actions (nattlig frysing av status, CSV-arkiv og backup). Alternativet «100 % GitHub med Issues/konto per bruker» er forkastet.

    Eierskap: Thomas eier GitHub- og Cloudflare-kontoene via FluxReveal-kontoene sine. Adresse: fluxreveal.com/Badehus/ (dokumentasjon: fluxreveal.com/Badehus/dokumentasjon/).

    Detaljdesignet i LLD (filnavn, felt, endepunkter, feilkoder, CSV-oppsett, nattlig jobb) er fortsatt Forslag – detaljdesign.

    De ti regelavklaringene

    Alle ti ble godkjent som foreslått av Thomas Gude Svensrud 25.10.2026.

    Å1 · 7-dagersregel vs. kvoteVedtatt 25.10.2026

    Spørsmål: Teller en booking gjort mindre enn 7 dager før mot sommerkvoten? Gjelder helgebegrensningen da?

    Vedtak: Booking gjort < 7 dager før teller ikke mot kvote; helgebegrensning oppheves også.

    Påvirker: shortNoticeCountsTowardQuota, regelmotor · Regler ⑤

    Å2 · Spontan innsjekkVedtatt 25.10.2026

    Spørsmål: Hvordan telles spontan innsjekk uten reservasjon?

    Vedtak: Teller i statistikk (bruk), ikke i kvote (skjer alltid < 7 dager før).

    Påvirker: spontaneousCheckinCountsTowardQuota, statistikk · Regler: innsjekk

    Å3 · Helg over to månederVedtatt 25.10.2026

    Spørsmål: Hvordan telles en helg som går over månedsskiftet (f.eks. fre 31. juli + lør 1. aug)?

    Vedtak: Kvoten følger datoens måned; helgeregelen følger helgen (fre–søn).

    Påvirker: summer.quotaMonthBy, summer.weekendBy · Regler: spesialtilfeller

    Å4 · Utenfor sommer (sep–mai)Vedtatt 25.10.2026

    Spørsmål: Gjelder noen begrensninger utenfor juni–august?

    Vedtak: Ingen begrensninger utover 3-måneders bookingvindu.

    Påvirker: offSeason

    Å5 · 3-måneders vinduVedtatt 25.10.2026

    Spørsmål: Hvordan regnes «maks 3 måneder frem i tid»?

    Vedtak: Rullerende: i dag + 3 kalendermåneder, samme dato.

    Påvirker: bookingWindow.mode · Regler ②

    Å6 · AvbestillingsrettVedtatt 25.10.2026

    Spørsmål: Hvem kan avbestille en booking?

    Vedtak: Alle brukere i samme husstand kan avbestille husstandens bookinger.

    Påvirker: cancelPermission, Worker-tilgangskontroll

    Å7 · StatistikkVedtatt 25.10.2026

    Spørsmål: Hvordan telles NOT_CONFIRMED og CANCELLED_LATE i statistikken?

    Vedtak: NOT_CONFIRMED vises separat (ikke regnet som bruk før bekreftet); CANCELLED_LATE teller i kvote, men ikke som bruk. En bekreftet NOT_CONFIRMED-booking («Vi brukte badehuset») blir COMPLETED.

    Påvirker: stats.*, statistikkpanel, statusmaskin · LLD: statusmaskin

    Å8 · ADMIN_CORRECTEDVedtatt 25.10.2026

    Spørsmål: Skal ADMIN_CORRECTED være en egen status?

    Vedtak: Ikke en status, men en hendelse i audit-loggen + flagg corrected: true; statusen forblir den faktiske tilstanden.

    Påvirker: statusmaskin, datamodell · LLD: statusmaskin

    Å9 · Personvern / GDPRVedtatt 25.10.2026

    Spørsmål: Hvordan forenes «ingen data slettes» med personvern når noen flytter?

    Vedtak: «Ingen sletting» gjelder bookinger. Utflyttede brukere deaktiveres og kan anonymiseres (navn → «Tidligere beboer Hus A»); husstanden beholdes.

    Påvirker: users.json (anonymized), adminfunksjoner · HLD: personvern

    Å10 · TidVedtatt 25.10.2026

    Spørsmål: Hva betyr 00:00, og hvilken tidssone gjelder?

    Vedtak: 00:00 = slutten av dagen (24:00) i Europe/Oslo, inkludert sommertid.

    Påvirker: timezone, periods, statusberegning · HLD: tid og status
